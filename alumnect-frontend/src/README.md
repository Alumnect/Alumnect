# Directory: `src/`

## 📋 Overview
Root source directory for the AlumNect Enterprise React Frontend (Vite + TypeScript). Built using the Enterprise Feature-Based Architecture combining self-contained feature modules (`src/features/`) with clear shared infrastructure layers (`src/app/`, `src/components/`, `src/hooks/`, `src/lib/`, `src/pages/`, `src/store/`, `src/types/`, `src/utils/`).
